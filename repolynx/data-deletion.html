RepoLynx User Data Deletion Instructions

Last updated: July 25, 2026

You may revoke access and request deletion of applicable data associated with RepoLynx Media Publisher.

Step 1 — Revoke Platform Access

Remove or revoke RepoLynx Media Publisher in the connected-app, business-integration, or permissions settings of the relevant Meta, Facebook, Instagram, or Threads account.

Revocation stops future authorized API operations after it is recognized by the platform and service.

Step 2 — Open a GitHub Issue

Open a data deletion request on GitHub
Issue title: RepoLynx Data Deletion Request

Include:

  • affected platform;
  • public username, profile name, Page name, or channel name;
  • brief description of the connection or data to delete.

GitHub Issues are public. Do not include passwords, access tokens, 2FA codes, recovery codes, private keys, payment information, or sensitive personal data.

Step 3 — Verification

We may request limited additional information to verify authorization. We will never request a social media password or recovery code.

Step 4 — Processing

After verification, we will delete or anonymize applicable identifiers, stored tokens, connection records, and publication records that are no longer required.

Information may be retained when required for security, fraud prevention, legal compliance, dispute resolution, or defense of legal claims.

Step 5 — Confirmation

We aim to acknowledge a valid request within 7 days and complete applicable deletion within 30 days, unless a longer period is required by law or technical constraints.

Confirmation or an explanation of retained information will be posted in the GitHub issue. Do not post verification data publicly; wait for maintainer instructions if additional verification is required.

Technical Notice

This page provides user-facing deletion instructions. It is not an automated Meta Data Deletion Callback endpoint. A callback, if required, must be implemented on the RepoLynx HTTPS backend and securely validate Meta's signed request.
